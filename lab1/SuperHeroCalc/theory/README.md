# Теория и подготовка к защите

Проект реализует вариант 27: пользователь вводит рост, вес, возраст, количество подтягиваний и продолжительность сна, после чего программа определяет уровень супергероя.

## Короткий ответ о работе

Приложение написано на Java с использованием Swing и разделено по MVC. `SuperHeroModel` хранит последние корректные данные и результат, проверяет значения и выполняет расчёт. `MainFrame` и `InputDialog` отвечают за интерфейс. `SuperHeroController` принимает действия пользователя, преобразует текст в числа и передаёт данные модели. Модель является активной: после расчёта она сама создаёт событие через `PropertyChangeSupport`, а подписанное главное окно получает событие и обновляет отображение.

Последние значения хранятся в модели в течение работы программы. При повторном открытии диалога контроллер передаёт их в `InputDialog`, поэтому поля восстанавливаются. Запись данных на диск по условию не требуется.
