# Калькулятор уровня супергероя

Учебный проект по дисциплине «Жизненный цикл разработки программного обеспечения».

**Автор:** Артём Фалько, группа 450504
**Язык разработки:** Java

## Описание

Приложение предназначено для определения уровня супергероя по введённым
пользователем параметрам: росту, весу, возрасту, количеству подтягиваний и
продолжительности сна.

В репозитории подготовлен пустой Maven-проект, в котором будут выполняться
дальнейшее проектирование и разработка приложения.

## Структура проекта

```text
SuperHeroCalc/
├── src/main/java/   — исходный код приложения
├── src/test/java/   — тесты
└── pom.xml          — конфигурация Maven
```

На текущем этапе функциональность приложения ещё не реализована.
