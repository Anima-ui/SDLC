# Глоссарий проекта «КиноНавигатор»

| Термин | Определение |
|---|---|
| КиноНавигатор | Веб-приложение для ведения личной коллекции фильмов и получения объяснимых рекомендаций |
| Гость | Неавторизованный посетитель, который может зарегистрироваться или войти в систему |
| Пользователь | Авторизованный владелец приватной коллекции фильмов |
| Администратор | Пользователь с ролью `ADMIN`, управляющий локальным каталогом и его синхронизацией |
| TMDB | Внешний источник общих метаданных о фильмах: названий, описаний, жанров, дат и постеров |
| Каталог | Общий набор карточек фильмов, доступных для поиска и просмотра |
| Локальный каталог | Сохранённые в базе данных карточки, доступные даже при отказе TMDB |
| Карточка фильма | Название, год, жанры, описание, постер и другие общие сведения о фильме |
| Активная карточка | Карточка, которая отображается в поиске и может участвовать в рекомендациях |
| Коллекция | Совокупность личных записей одного пользователя о фильмах |
| Личная запись | Связь пользователя с фильмом, содержащая статус, дату просмотра, оценку и заметку |
| Хочу посмотреть | Статус фильма, который пользователь планирует посмотреть |
| Просмотрен | Статус завершённого просмотра; позволяет указать дату, оценку и заметку |
| Брошен | Статус фильма, просмотр которого прекращён; такой фильм исключается из рекомендаций |
| Оценка | Целое число от 1 до 10, выражающее мнение пользователя о просмотренном фильме |
| Рекомендация | Предложенная пользователю активная карточка фильма с объяснением причины выбора |
| Холодный старт | Ситуация, когда у пользователя меньше трёх оценок и персональный профиль ещё нельзя построить |
| Импорт коллекции | Загрузка личных записей из CSV после проверки и подтверждения пользователем |
| Предварительный просмотр импорта | Проверка CSV с разделением строк на новые, существующие и ошибочные без изменения коллекции |
| Экспорт коллекции | Выгрузка личных записей текущего пользователя в CSV UTF-8 |
| Дубль | Повторная личная запись того же пользователя для того же фильма |
| Синхронизация каталога | Получение и сохранение актуальных метаданных фильмов из TMDB |
| Запуск синхронизации (SyncRun) | Один запуск обновления каталога со временем начала и окончания, статусом, числом обновлений и описанием ошибки |
| Сеанс | Ограниченное по времени состояние авторизации пользователя на сервере |
| Прецедент | Завершённый сценарий взаимодействия актёра с системой, дающий полезный наблюдаемый результат |
| Актёр | Внешняя роль человека или системы, взаимодействующая с «КиноНавигатором» |
